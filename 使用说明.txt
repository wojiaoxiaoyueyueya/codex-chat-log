codex智入 1.3.0
纯本地、免安装的 Windows Codex 聊天备份与迁移工具

【公开版重要边界】
本仓库仅分发工具、源码、虚构测试和说明，原 GitHub 聊天备份/云端同步方案已停止使用。
导入是安全合并所选项，不是清空目标电脑后完整替换；“成功”仅表示本次选中的可导入项完成。
冲突聊天、父历史不兼容的分支仍可能跳过。已有同一包在不同目标电脑上结果不同的反馈，尚未彻底解决。
确认项目、父聊天、分支及消息均完整前，请保留原始包、源电脑数据和导入前回滚副本。
详细边界请查看仓库 README.md 和 KNOWN_ISSUES.md，不要把聊天包或真实诊断资料上传到公开仓库。

【1.3 操作中阅读、单一成品与跨版本兼容】
· 导出、核对、导入和回滚的长任务在后台运行。准备好只读浏览副本后，左侧仍可选聊天、搜索，
  右侧可阅读、复制、翻页和切换核对中的本机/备份对话；不再整段操作都锁住浏览区。
· 操作中看到的是“操作前的只读副本”，不是正在被替换的数据库。写入按钮、目录切换和导入勾选仍锁定，
  避免同时开始另一项操作。导入完成刷新后才能看到新增内容。正常退出请求等待期间需要先保存工作。
· 浏览副本的数据库独立复制，会话使用只读硬链接以免重复复制大文件；跨盘/不支持硬链接时才复制会话。
  副本不含 auth.json 或 config.toml。工具正常关闭时清理，不影响你的原记录及回滚副本。
· 成功导出只发布一个 .czr 文件。正常桌面导出的临时包移到软件缓存；若另选其他磁盘，则使用该磁盘的
  隐藏临时目录，保证最终文件一次重命名完成。临时文件不是成品，不能拿来导入，也不需要手动操作。
· 新电脑选择“codex智入-聊天备份-日期-时间.czr”导入。资源管理器可能隐藏扩展名，可在属性中确认文件类型。
· 核对阶段提前检查表结构。不再等确认导入后只弹英文 Incompatible database table。
· 针对 thread_turns.root_turn_id、thread_items.started_at_ms / completed_at_ms 等已知可空元数据差异，
  保留目标 Codex 原有表结构和数据库迁移记录；较新元数据另存到聊天附件中的兼容文件，不直接丢弃。
· 兼容文件位于 attachments\codex-zhiru-history-compat-v1；导出仍会携带，按选择过滤，之后用新版工具将
  对应聊天新增/更新到支持这些字段的 Codex 时，可恢复目标为空的值。不会覆盖目标已有值或未选聊天。
· 这是有限的字段兼容，不是任意 Codex 版本互转。未知字段、主键/表结构或必填字段不兼容时，核对页会列出
  差异并禁用导入；请把两台电脑的 Codex 更新到相同版本后重新核对。不会伪造数据库升级记录或强行覆盖。
· 两台电脑都请使用 1.3 及以上工具进行后续迁移，以保留和识别兼容元数据。原有 .czr 包可直接使用，无须重导。

· 读取单条对话时保持聊天列表可用；快速点选多条聊天时，只显示最后一次选择的结果。
· 导入核对列表也支持连续切换和稳定选中；真正导入、导出和回滚时仍保留必要的操作保护。

· ```text 这样的围栏显示为独立代码块，保留缩进；代码块右上角可直接复制代码。
· 每条消息右上角“复制”复制完整原文，保留原始 Markdown。阅读排版不会改写聊天文件。
· 链接在正文里显示为链接文字，单击复制地址；图片显示附件提示。历史内容不会作为网页或脚本执行。
· 统一字体、留白、圆角按钮、搜索框和标签页，缩小顶部区域，为阅读保留更多空间。
· 使用 Windows 原生组件完成排版，无需额外安装浏览器或联网加载字体。

  隐藏只是为了浏览清楚；导出仍包含全部记录。核对列表的内部助手分组可展开，并单独勾选。

速度参考：开发电脑同一份约 18 MB 的虚拟会话文本，旧版导出 1.58 秒，新版 0.47 秒。
本机约 200 条记录的只读扫描约 0.4 秒，进程识别约 16 毫秒。实际时间取决于数据量、磁盘和附件大小。

【打开软件】
双击同目录的“codex智入.exe”。不要单独移动 exe：src、lib、vendor 文件夹必须一起保留。
本工具不联网，不需要 GitHub、账号授权或另外安装 Python。首次打开会校验并解压自带运行环境。
适用于 Windows 10/11 x64 和 .NET Framework 4.8；不是 macOS/Linux/ARM 原生版本。
这是独立的本地工具，不是 OpenAI 官方迁移产品。

【旧电脑：一键导出】
1. 打开工具，确认“数据目录”和聊天数量。
2. 点击“一键导出到桌面”，按提示先保存 Codex 草稿和编辑器文件。
3. 工具请求相关软件正常退出。完成后桌面出现：
   codex智入-聊天备份-日期-时间.czr
这是一个完整离线包，包含该数据目录的普通聊天、归档、项目分组、分支/共享历史及支持的聊天附件。
只携带完成后生成的 .czr 文件及完整工具；不要选择 .partial 临时文件或把无扩展名的临时显示当成第二份备份。
每次导出产生新文件，不会覆盖或删除上次的备份。本机聊天也不会因导出而删除。

【新电脑：一键导入并核对】
1. 将 .czr 聊天包和完整工具文件夹复制到新电脑。
   也可以携带“发布包”里的工具 ZIP，先解压后再双击 exe。不要在压缩包内部直接运行。
2. 建议先安装并打开新电脑的 Codex、登录一次，然后退出。
   工具也支持空数据目录，但之后仍需自己安装/登录 Codex。
3. 点击“一键导入 / 核对”，选择 .czr 包。等待校验和内容比较。
4. 左边勾选，右边直接阅读对话；可切换备份/本机内容，再点击“确认导入所选聊天”。
5. 成功后重新打开 Codex，检查普通聊天、归档和分支。确认正常前保留源包及回滚副本。

导入规则是“安全合并”，不是清空新电脑的所有记录：
· 新电脑没有的聊天：新增。
· 同一聊天，包里在本机历史后增加了消息：更新。
· 内容完全相同：跳过，不出现在待更新列表中。
· 同一聊天，本机在包的历史后增加了消息：保留本机，不出现在待更新列表中。
· 两边各自改写/续写，不能证明谁包含谁：显示冲突，禁用勾选，保留本机和原始备份包。
· 本机独有的聊天：保留，不删除。
例如新电脑的 hello 对话更完整，hello 不会被旧包覆盖，也不会列为需要更新。
判断依据是完整历史中的消息和工具结果，不是文件修改时间或电脑时钟。
仅改标题或项目名称、而对话内容完全相同的聊天，不会单独覆盖本机元数据。

【项目、分支与预览】
左侧按 Codex 保存的置顶、项目、自定义分组、聊天与归档展示，可按聊天名称或项目名称搜索。
点击父聊天前的小三角展开分支。“显示内部助手 / 安全审查”可显示隐藏的自动助手记录。
显示顺序：保存的聊天名称、标题、索引名称、子助手名称；都缺失时才显示“未命名聊天 + 短编号”。
没有单独项目归属的子对话，在界面上跟随父聊天分组；不改动数据库中的原有归属。
右侧以“你 / Codex”对话形式阅读，每页最多 60 条，可前后翻页，支持排版阅读、文字选择和完整原文复制。
“显示工具记录”可补充工具调用和结果。图片只显示附件提示/引用，不做图片缩略图；不执行 HTML 或历史命令。
导入核对页单击一条记录，右边就显示包里的对话；通过下拉框切换到本机对话。本机聊天也可从左侧打开。
“全部取消”不会退出软件，也不会删除任何聊天；它只把当前导入勾选清空，可以重新勾选。
全部勾选已经选满时，“勾选全部可导入项”禁用；没有勾选时，“全部取消”和“确认导入”禁用。

分支需要的共享历史会一起检查。目标已有兼容的父历史时会复用，不覆盖父聊天的新内容。
如果父聊天必须新增或更新，请保留父子聊天的勾选；单独取消必要的父聊天会停止导入。
缺失或冲突的共享历史不能安全拼接时，相关分支禁用导入，不会假装恢复成功。

【退出相关软件的规则】
“操作前请求正常退出 Codex”默认开启，导出/核对/导入/回滚前会提示保存工作。
识别到 Codex 主程序和后台会话后，先请求窗口关闭，再发送 Windows 的正常应用退出通知。
也会识别实际托管 Codex 会话的编辑器。通知严格限定到已识别的进程，不启用强制退出选项。
开发中已用独立测试窗口验证窗口关闭和应用退出通知；当前 Codex 没有被拿来做关闭测试。
不会强杀进程、结束所有终端或关闭无关软件。未保存文件会由相关软件自行提示。
某些 Codex 托盘进程、终端 CLI、IDE 后台会话没有可关闭的窗口，需要你自行退出。
45 秒后仍检测到它们，操作会停止；不会在已知仍运行的情况下覆盖聊天数据库。
导入期间请勿重开 Codex、关闭工具、电源或拔出磁盘。读聊天/刷新不会自动关闭 Codex。

【自动备份与回滚】
每次正式导入之前，原聊天状态移到同一磁盘的回滚目录，例如：
C:\Users\你的用户名\Codex-chat-merge-backups\zhiru-日期-时间-编号\
实际路径会在导入成功提示中显示。回滚副本不在可随意删除的临时缓存里。

方式一：在软件中点击“恢复到导入前”，恢复最近一次本工具导入前的状态。
方式二：即使删除了原工具，也可以打开该回滚目录，双击“恢复到导入前.cmd”。
        独立回滚工具要求先自行退出 Codex/CLI/IDE，不强杀进程，且自带离线运行环境。

导入发生可恢复错误时会尝试自动回滚；如果 Codex 中途重开而无法安全回滚，会保留事务记录并提示路径。
异常断电或关闭进程后，先回滚再继续导入。即使主数据库暂时不在原位置，软件的回滚按钮仍可处理。
回滚会恢复导入前的聊天状态；导入后的状态也留存在“state-before-rollback”中，不直接销毁。
确认迁移正常前，不要删除任何回滚目录。

【寻找数据和迁移范围】
自动识别当前用户的标准 .codex 目录及 CODEX_HOME 指定的自定义目录，包含其中的普通/归档聊天。
不扫描整块硬盘，不跨越其他 Windows 用户权限，也不把散落的历史备份重复当成当前数据。
如果聊天放在其他目录，请点“选择其他目录”，选择包含 state_5.sqlite 的数据目录。
多个数据目录可分别导出，再按需要导入同一目标。切换目录后旧导入预览会失效，避免写错位置。

支持当前已验证的 state_5.sqlite / thread_history_1.sqlite 及相应会话格式。
Codex 将来改变数据库结构时可能拒绝导入，请保留包并更新工具，不要手动强行替换数据库。
跨版本出现不兼容会在隔离合并阶段停止，原数据不变。暂未在另一台物理电脑上完成真实 Codex 启动验收。

包含：会话文本、历史数据库、项目分组信息、聊天索引、分支及共享历史，支持目录中的附件/可视化素材。
不包含：auth.json、config.toml、安装身份、浏览器登录、插件、自动化任务、项目源代码/工作区文件。
旧机器项目文件夹不存在时，聊天仍保留，但继续编码前需要手动打开新机器上的对应项目目录。
聊天中引用的外部桌面图片、网络图片或任意工作区文件，不保证在包内；需要另行迁移那些文件。

【隐私与磁盘空间】
.czr 是带逐文件 SHA-256 校验清单的 ZIP 容器，不是加密文件，不保证对恶意篡改者的身份认证。
只导入自己或可信来源的包。不要公开上传到公共仓库；可使用你自己的加密磁盘/U盘保存。
离线包保留原对话文字，不自动删除曾在聊天里粘贴的密码或密钥；不复制账号配置文件。
导入不会替换新电脑登录信息；新电脑需要使用自己的登录状态。
校验、合并和回滚需要额外空间，建议至少预留源数据和本机聊天合计大小的 4 倍空余空间。
临时核对副本位于 %LOCALAPPDATA%\CodexZhiru\jobs，对话浏览缓存位于旁边的 views 文件夹。
操作期间的只读浏览副本也在 jobs 中；它会保留到工具关闭，以免后台导入成功清理原预览时打断阅读。
正常完成/关闭工具时会清理当前任务和浏览缓存。失败尝试的中间目录会及时清理，但原预览保留供重试。
如果软件曾被强制终止，可在确认所有 codex智入 窗口和工作进程退出后清理 jobs 和 views；不要删除回滚目录代替它。

【项目文件】
codex智入.exe：日常使用入口。
src\App.cs：Windows 桌面界面源码。
src\RichMessage.cs：本地 Markdown 阅读排版、代码块与复制功能。
src\offline.py：本地扫描、独立只读浏览副本、缓存打包、比较、导入与恢复流程。
src\sidebar.py：读取 Codex 侧栏分组、置顶和排序，辨认主聊天与内部助手。
src\win_process.py：快速识别相关进程，以及正常窗口关闭/应用退出通知。
src\asset_conflicts.py：同名附件分别保留，并修正导入记录中的对应引用。
lib\chat_merge.py：数据库/项目/分支合并、已知历史字段兼容与保留、消息位置修复、事务回滚。
lib\chat_select.py：按完整消息内容比较新旧、共享历史依赖检查，按选择保留兼容元数据。
lib\chat_snapshot.py：文件白名单、数据库安全整理等支持功能；本工具不调用云端上传流程。
vendor：随工具携带的 Python 运行环境压缩包（内含其许可证）。不要删除。
.runtime：首次启动解压的运行环境，可在工具完全退出后删除，下次会离线重建。
build.ps1 / package.ps1：开发者编译和制作便携包脚本，日常用户不用运行。
tests、lib\test_chat_*.py：隔离的虚构开发验证资料，不是你的聊天备份。

开发回归使用隔离虚拟数据。测试通过不代表所有版本、所有真实数据和所有目标电脑都已完成迁移验收。
不要拿真实 Codex 数据目录代替测试目录；不要在开发测试中关闭当前工作的 Codex。
