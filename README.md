# codex智入

纯本地运行的 Windows Codex 聊天备份与迁移工具。当前公开版本：**1.3.0（实验性）**。

仓库只分发程序、源码、虚构测试和说明，**不存储任何个人聊天记录或登录配置**。原有 GitHub 聊天备份／云端同步方案已停止使用。

> 注意：导入是“安全合并所选聊天”，不是清空目标电脑再完整替换。提示成功只代表所选项完成。冲突聊天及共享历史不兼容的分支可能被跳过；目前不保证任意已有数据、任意 Codex 版本之间的完整迁移。详见[已知问题](KNOWN_ISSUES.md)。

## 下载和运行

建议从 [Releases](https://github.com/wojiaoxiaoyueyueya/codex-chat-log/releases/latest) 下载完整的 `codex智入-1.3.0-Windows-x64.zip`，解压后双击 `codex智入.exe`。

也可以在仓库主页选择 **Code → Download ZIP**，解压完整目录后运行根目录的 exe。

- 支持 Windows 10/11 x64，需要 .NET Framework 4.8。
- 免安装，自带离线 Python 运行环境，不需要 Git、GitHub CLI、账号授权或联网。
- 不要只复制 exe；`src`、`lib`、`vendor` 必须一起保留。
- 本项目不是 OpenAI 官方迁移工具。

## 使用方式

### 旧电脑：一键导出

1. 打开工具，确认数据目录和聊天列表。
2. 保存 Codex 和相关编辑器中的未完成工作，点击“一键导出到桌面”。
3. 根据提示正常退出相关 Codex 会话。工具不会强杀进程。
4. 导出完成后，桌面生成一个 `codex智入-聊天备份-日期-时间.czr` 文件。

`.czr` 是需要携带到新电脑的聊天包，不是工具 ZIP。打包临时文件不是可导入备份。导出不删除源聊天，也不覆盖已有备份。

### 新电脑：导入并核对

1. 把 `.czr` 和完整工具文件夹复制到新电脑。两台电脑建议使用相同版本的 Codex 以及本工具。
2. 建议先在新电脑启动 Codex 并登录一次，之后保存工作并退出。
3. 点击“一键导入／核对”，选择 `.czr`；只核对不会替换聊天。
4. 阅读顶部统计和每条聊天的原因，按需选择，再点击“确认导入所选聊天”。
5. 启动 Codex，逐项检查项目、父对话、分支和历史消息。确认完整前不要删除聊天包或回滚副本。

| 核对结果 | 处理 |
| --- | --- |
| 目标没有的聊天 | 可选择新增 |
| 备份是目标历史的后续 | 可选择更新 |
| 内容相同 | 跳过 |
| 目标是备份历史的后续 | 保留目标，跳过 |
| 双方历史不同 | 保留目标，禁止直接覆盖 |
| 分支所依赖的父历史无法安全复用 | 禁止直接导入该分支 |

这套保守规则可能导致只导入一部分。**不要把“导入了 N 条”理解为“备份内全部聊天已恢复”。** 工具尚未提供任意冲突历史的自动拼接或“冲突另存为独立聊天”功能。

## 功能与边界

- 普通聊天、归档、项目分组、分支和共享历史的离线打包。
- 保留原始对话文字，逐文件 SHA-256 校验；导入前保留回滚副本。
- 保护目标端登录文件及配置，不迁移账号登录状态。
- 长任务在后台进行；只读浏览副本准备好后可继续阅读、翻页、搜索、复制。
- 对话支持常用 Markdown 排版，不执行历史 HTML、命令或链接。
- 有限兼容已知的可空历史元数据字段，不伪造 Codex 数据库迁移记录。

不包含项目源码、工作区文件、插件、浏览器登录或云端不可访问的聊天。聊天引用的外部图片或文件需要自行迁移。不是 macOS/Linux/ARM 原生程序。

## 隐私和回滚

`.czr` **没有加密**，保留聊天原文，可能包含曾经粘贴的密码、密钥或工作资料。不要把它上传到本仓库、Issue、公开网盘或公共 Release。

每次正式导入前保存回滚目录，实际位置会在成功提示中显示。可使用“恢复到导入前”，或备份目录中的独立 `恢复到导入前.cmd`。确认完整前不要清理回滚目录。

本仓库内的测试是临时生成的虚构数据；不包含开发者的聊天快照、数据库、诊断包或真实聊天截图。更多要求见 [SECURITY.md](SECURITY.md)。

## 源码结构

| 文件 | 用途 |
| --- | --- |
| `codex智入.exe` | 用户运行入口 |
| `src/App.cs` | Windows WPF 界面、后台工作与预览交互 |
| `src/RichMessage.cs` | 本地 Markdown 排版和复制 |
| `src/offline.py` | 扫描、浏览副本、离线包、核对、导入和回滚流程 |
| `src/sidebar.py` | 侧栏项目、置顶、分支和内部助手分类 |
| `src/win_process.py` | 进程识别与正常退出请求 |
| `src/asset_conflicts.py` | 附件同名冲突分别保留 |
| `lib/chat_merge.py` | 隔离合并、历史位置修复、已知字段兼容、事务回滚 |
| `lib/chat_select.py` | 内容比较、选择及共享历史依赖检查 |
| `lib/chat_snapshot.py` | 复用的本地快照辅助函数；不是 GitHub 上传入口 |
| `vendor/` | 自带 Python 运行环境及其随附许可证 |
| `tests/`、`lib/test_chat_*.py` | 虚构数据与界面回归测试 |

旧的 `UPLOAD-CHAT-BACKUP.cmd`、`UPDATE-CHAT-RECORDS.cmd`、GitHub 下载脚本和云端聊天分卷不是本版本的使用方式。

## 开发和验证

使用 PowerShell 7，或能正确读取 UTF-8 的 PowerShell 环境：

```powershell
.\build.ps1
.\package.ps1
.\tests\run-ui.ps1
.\tests\run-data.ps1
```

`package.ps1` 会保留已有输出，重复打包前请另行保存原发布包。数据测试只操作临时虚构目录，不应拿真实 Codex 数据代替测试目录。有关正常退出的原生接口测试只针对新建的测试窗口，不针对正在运行的 Codex。

历史开发验证包含 89 项数据回归和 38 项界面检查；这不等于已在所有电脑及 Codex 版本完成真机验收。公司端已有历史发生冲突时的完整迁移仍是[已知问题](KNOWN_ISSUES.md)。
